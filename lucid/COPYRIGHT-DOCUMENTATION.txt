Gedit Source Code Browser
=========================

A source code class and function browser plugin for Gedit 3. 

* Author: Micah Carrick

This plugin will add a new tab to the side pane in the Gedit text editor which
shows symbols (functions, classes, variables, etc.) for the active document. 
Clicking a symbol in the list wil jump to the line on which that symbol is 
defined.

See the [ctags supported languages](http://ctags.sourceforge.net/languages.html)
for a list of the 41 programming languages supported by this plugin.


Requirements
------------

This plugins is for Gedit 3 and is **not compatible with Gedit 2.x**. 

The Gedit Source Code Browser plugin uses 
[Exuberant Ctags](http://ctags.sourceforge.net/) to parse symbols
out of source code. Exuberant Ctags is avaialable in the software repository for
many distributions. To make sure you have ctags correctly installed, issue
the following command:

    ctags --version
    
Make sure that you see *Exuberant* Ctags in the version output.


Installation
------------

1. Download this repository by clicking the Downloads button at the top of the 
   github page or issue the following command in a terminal:

    git clone git://github.com/Quixotix/gedit-source-code-browser.git

2. Copy the file `sourcecodebrowser.plugin` and the folder `sourcecodebrowser` to
   `~/.local/share/gedit/plugins/`.

3. Restart Gedit.

4. Activate the plugin in Gedit by choosing 'Edit > Preferences', the selecting
   the 'Plugins' tab, and checking the box next to 'Soucre Code Browser'.
   
5. (Optional) If you want to enable the configuration dialog you need to compile
   the settings schema. You must do this as root.

    cd /home/&lt;YOUR USER NAME&gt;/.local/share/gedit/plugins/sourcecodebrowser/data/
    
    cp org.gnome.gedit.plugins.sourcecodebrowser.gschema.xml /usr/share/glib-2.0/schemas/
    
    glib-compile-schemas /usr/share/glib-2.0/schemas/

Known Issues
------------

* CSS is not supported. This issue is about ctags and not this plugin. You can
  [extend ctags](http://ctags.sourceforge.net/EXTENDING.html) to add support for 
  any language you like. Many people have provided their fixes to on internet 
  such as this [patch for CSS support](http://scie.nti.st/2006/12/22/how-to-add-css-support-to-ctags).
  
* PHP is supported, however, PHP5 classes are not well supported. This is again
  an issue with ctags. There are numerous fixes to be found onn the internet
  such as these 
  [patches for better PHP5 support](http://www.jejik.com/articles/2008/11/patching_exuberant-ctags_for_better_php5_support_in_vim/).

# Lucid

Lucid is a GTK4 frontend in the Debian gedit 48.1 source fork for Luxe.
The GTK3 application and Debian source baseline remain alongside it. The
new target uses GtkSourceView 5, GTK4 VTE and libspelling instead of GTK3
Tepl, libgedit-gtksourceview and the old plugin loader. The upstream gedit
modeline parser is adapted directly, preserving its copyright/license.
This is a first release, not full gedit feature parity.

## Included

- Tabbed text editing, undo/redo, clipboard, search/replace, go-to-line.
- Automatic syntax highlighting and a manual language picker.
- Asynchronous loading/saving through GtkSourceView, retaining encoding and
  line endings and refusing to overwrite externally changed files.
- Save/Discard/Cancel handling for modified documents.
- File browser sidebar (F9), modelines, selection highlighting, statistics,
  sort lines, spell checking, text zoom and date/time insertion.
- Session Saver, Embedded Terminal (F4) and Color Picker integrated directly
  into the application and its single package. No optional plugin packages.
- Named sessions and periodic recovery snapshots under
  `$XDG_STATE_HOME/lucid` (normally `~/.local/state/lucid`). Recovered edits
  become separate modified documents, requiring Save As; this protects
  newer disk content. Named sessions open alongside current tabs.
- Twenty bundled syntax color schemes, selectable in Preferences:
  Catppuccin Latte/Frappé/Macchiato/Mocha, Nord/Dark and Nord Light,
  Solarized Dark/Light, Gruvbox Dark/Light Medium, Tokyo Night Dark/Storm/Light,
  Dracula, One Dark, Rosé Pine/Moon/Dawn and Everforest Dark/Light Medium.
  Palette origins, pinned revision and MIT license are in data/styles.

Lucid uses its own executable, desktop entry and settings schema
(`org.luxe.Lucid`). Installing it does not replace gedit or change the
system's default editor. A shell starts only when the terminal is opened.
Hiding it keeps the shell alive; quitting Lucid closes it.

## Building on Debian 13

Build dependencies: cmake, build-essential, pkg-config,
libgtk-4-dev, libadwaita-1-dev, libgtksourceview-5-dev, libvte-2.91-gtk4-dev, libspelling-1-dev.

From this directory:

```
cmake -S . -B build -DCMAKE_INSTALL_PREFIX=/usr -DBUILD_TESTING=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Integration tests run in an isolated nested X session via
`cmake/RunNestedX.py` with private D-Bus, settings and session directories;
nothing is installed and the live desktop is untouched.

Build the Debian package with `cpack -G DEB` from the configured build
directory. Install using
`sudo apt install ./lucid_0.1.0-1+luxe8_amd64.deb` from the artifacts/debs folder;
APT supplies the normal Debian runtime libraries.

## Scope and known differences

This target does not load gedit's old binary/Python plugins. Only the three
selected optional features are included; other optional plugin sources
are retained as reference but are not installed. Existing gedit settings
and sessions are not migrated. Printing, multiple editor windows, regex
search controls and a manual encoding chooser are not yet exposed by this
first frontend. Source saving still preserves detected encodings.

  <title>Bookmarks</title>

  <p><app>gedit</app> bookmarks allow you to highlight important lines of text
  within your document or program, making them easier to find. You can also
  move up or down between bookmarks, making document navigation a bit
  faster.</p>

  <steps>
    <title>To enable the plugin:</title>
    <item>
      <p>Press the menu button in the top-right corner of the window and select
      <guiseq><gui style="menuitem">Preferences</gui>
      <gui style="tab">Plugins</gui></guiseq>.</p>
    </item>
    <item>
      <p>Select <gui style="menuitem">Bookmarks</gui> to enable the plugin.</p>
    </item>
  </steps>

  <steps>
    <title>Bookmarks are inserted and removed by completing the same action. To 
    insert or remove bookmarks:</title>
    <item>
      <p>Navigate to the line where you want to insert or remove the
      bookmark.</p>
    </item>
    <item>
      <p>Press <keyseq><key>Ctrl</key><key>Alt</key><key>B</key></keyseq>, or
      open the menu in the top-right corner and select
      <gui style="menuitem">Toggle Bookmark</gui>.</p>
    </item>
  </steps>
  
  <list>
    <title>To move between bookmarks:</title>
    <item>
      <p>Press <keyseq><key>Ctrl</key><key>B</key></keyseq> to move to the next
      bookmark.</p>
    </item>
    <item>
      <p>Press <keyseq><key>Ctrl</key><key>Shift</key><key>B</key></keyseq> to
      move to the previous bookmark.</p>
    </item>
  </list>

  <note>
