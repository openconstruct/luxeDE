luxe is a continuation of gtk LXDE. It has been upgraded and patched massively and runs on gtk4.

luxe is in a beta-type state currently, builds have been provided for 2 distros, Debian 13 and Ubuntu 24+



    luxepanel -> LXPanelPanel

    pcmanager -> PCManFMFile op

    luxeterm -> LXTerminalGTK4

    luxesession -> LXSessionSession

    luxeappearance -> LXAppearanceTheme

    luxeappearance-obconf -> LXAppearance ObConf

    luxehotkey -< LXHotkeyGlobal

    luxeinput -> LXInputKeyboard

    luxerandr ->LXRandRMulti-monitor

    luxetask ->LXTaskProcess

    luxepolkit ->LXPolkitPolicyKit

    luxemenu-data =>LXMenu DataXDG

There is also quite a bit of non-de specific apps to make a complete desktop system.

    matinee - video/music player powered by ffmpeg, new

    frame - gtk image viewer with light editing tools, new

    shotty - port of https://github.com/Tomaszal/simpleshot-gtk

    luxenotify - notification system, new

    luxup - update notifier, new

    luxepower - power manager, mostly a frontend for TLP, new

    luxesettings - hub for DE settings, new

    debinstall - gtk4 frontend for gdebi-core, new

    lucid - GTK4 port of gedit, no plugins but comes bundled with the best ones

    luxurystore - gtk4 port of synaptic, with a lot of added features

    luxedm - heavily updated for of slim ( debians version which was updated until 2024) 

    slab - gtk4 dock, inspired by plank, new

Get it from releases!   https://github.com/openconstruct/luxeDE/releases
