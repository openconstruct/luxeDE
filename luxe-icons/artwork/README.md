# Luxe application artwork

Original editable SVG artwork, Copyright (C) 2026 Jerry Howell.
SPDX-License-Identifier: GPL-3.0-or-later (see ../LICENSE-Papirus for license text).

Lucid: blue paper and pen. PCManager: teal open folder. Shotty: coral capture
viewfinder. Frame: amber framed landscape. Matinee: violet playback tunnel.
The family shares a 48-unit grid, rounded tile, solid colors and a small lower
edge. Opaque tiles keep the glyph contrast intact in both light and dark mode;
Luxe-Light receives its own copy and Luxe-Dark inherits the same application art.

`luxe:` targets in aliases.json resolve here, while ordinary targets continue
to resolve against the pinned upstream themes. Generic upstream icon names
are preserved. SVG files are the source of truth; previews are not installed.
