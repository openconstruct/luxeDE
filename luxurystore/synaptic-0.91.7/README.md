# LuxuryStore's Synaptic sources

This subtree contains the maintained Synaptic-derived APT backend and Luxe GTK4
frontend. Build from `luxurystore/CMakeLists.txt`, not with upstream autotools.
The monorepo's `LUXE-BIBLE.md` and `ci/README.md` document dual APT 6/7 inputs,
tests and packaging. Upstream attribution and license terms remain in AUTHORS,
COPYING and the source headers. Luxe integration is copyright Jerry Howell.
